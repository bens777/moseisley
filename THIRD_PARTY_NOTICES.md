# THIRD_PARTY_NOTICES.md

Records third-party source that was copied or adapted into MyChief.

As of now: **no third-party source code has been copied or adapted.**

Reference projects (LifeOS, Sovereign-OS, OpenClaw, Hermes Agent, TheAlgorithm, Dex, Whisper)
were studied at the architecture/concept level only, per MASTER_SPEC.md §8–9. Concepts and
independent reimplementations are not copies.

unless their license requires a notice (none currently do beyond standard attribution in
package metadata).

If source is later copied/adapted, each entry must record: project, source URL, license at
time of copying, files/components reused, and required notices.
